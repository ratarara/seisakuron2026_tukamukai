# A1 共通取っ手の設計値

## 設計方針
既存のハンドで各ピースを把持するため、ピース上面に共通の取っ手を設ける。
取っ手の長手方向は、ピースの基準姿勢での長い方向にそろえる。
ピースへの取り付けは一体造形を想定する。

## 寸法（単位：mm）
| 項目 | 設計値 |
|---|---|
| 把持部の長さ | 8 |
| 把持部の厚さ | 4 |
| 取っ手の全高（ピース上面から） | 12 |
| 土台 | 8 × 6、高さ2 |
| 傾斜部 | 高さ2、左右それぞれ水平に1ずつ縮小 |
| 上部 | 高さ8（上端の面取りを含む） |
| 上面の面取り | 4辺にC0.3 |

## 設計根拠
班内の上面視の簡易干渉計算に基づき、把持部を長さ8、厚さ4とした。
把持前のハンドと取っ手の隙間は片側2を想定する。

## 確認状況
STEPモデルが単一の有効な実体であることと、上記寸法を確認した。
高さと土台形状は試作値であり、実機による把持・干渉試験は未実施。
土台を追加したため、班内の元の干渉計算結果はそのまま適用できない。
