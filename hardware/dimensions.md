# 設計値

ハードの寸法と設定値の一覧です。ソフトの担当（B：認識、C：動作、D：司令塔）は、ここの値をプログラムの設定ファイルに使います。**値を変えたら、ソフトの担当に必ず知らせてください。**

単位は特に書いていなければ mm です。未定の値は「未定」と書き、決まったら埋めます。

## マスとケース

| 項目 | 値 | 決めた理由・メモ | 使う人 |
|---|---|---|---|
| 1マスの大きさ | 未定 | 取っ手とグリッパの寸法から決める（#9） | B・C・D |
| 盤面のマス数 | 8 × 8 | ピース16個分 | D |
| ピース外形とマスのすき間（片側） | 0.5〜1（予定） | すり鉢で横に動ける余地を残す（#14 で確定） | A |
| ケースの外形 | 未定 | | C |
| 枠の入り口の面取り | 未定 | | A |
| ArUco マーカーの大きさ | 未定 | | B |
| ArUco マーカーの位置 | 未定 | ケースの3つの角（#16） | B |

| 項目 | 値 | 決めた理由・メモ | 使う人 |

| すり鉢の深さ | 未定 | | A |
| 突起の形 | 未定 | ビー玉を埋め込む or 3D プリントの半球 | A |

| ずれを戻せる範囲 | 未定 | 半マス未満の予定（#14 の実験で測る） | C |

## ピースと取っ手

| 項目 | 値 | 決めた理由・メモ | 使う人 |
|---|---|---|---|
| ピースの厚み | 未定 | | C |
| 取っ手の形 | 未定 | 板状・角形（向きが決まるように）。全ピース共通 | A・C |
| 取っ手の幅・厚み | 未定 | グリッパの指の開き幅に合わせる | C |
| 取っ手の高さ（ピース上面から） | 未定 | 指がケースや隣のピースに当たらない高さ | C |
| 取っ手の位置 | ピースの重心の真上 | ソルバーが返す重心の位置をつかむ | C・D |
| 置くときにハンドを開く高さ | 目標の数mm上（予定） | 握ったままだとすり鉢が働かない | C |
