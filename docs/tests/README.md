# 動作確認の進め方と記録方法

## 動作確認の順序

| 順番 | テスト | 確認すること |
| --- | --- | --- |
| 1 | T2 ソルバー（#57） | 4×4の盤面を I・S・L・L で埋められることと、解けない組み合わせでは「解なし」になることを確認する。 |
| 2 | T3 つかむ・置く動作（#58） | Gazeboで確認してから実機で試す。指定した位置・向きと実際に置かれた位置・向きを比べ、成功回数とずれを記録する。 |
| 3 | T4 ピース認識（#59） | 種類・位置・向きが分かっているピースを机に置き、認識結果と比べる。照明や置き方を変え、正答率とずれを記録する。 |
| 4 | T5 通しの動作（#60） | I・S・L・L を順に認識し、つかんで置き、4×4の盤面を埋める。複数回試し、成功率と、失敗した場合はどの段階で失敗したかを記録する。 |

## 記録のひな形

テストごとに以下のひな形をコピーし、`docs/tests/` に保存する。

- 実施日：
- テスト名・関連Issue：
- 確認したバージョン（PR番号またはコミットID）：
- 条件（使用環境、ピースの種類・位置・向きなど）：
- 手順：
- 期待する結果：

| 試行 | 実際の結果 | 成功／失敗 | 測定値・気づいたこと |
| --- | --- | --- | --- |
| 1 | | | |

複数回試した場合は、成功回数／試行回数も記録する。
位置のずれは mm、角度のずれは ° で記録する。

問題が見つかった場合は、再現手順と結果を担当者のIssueにコメントする。
対応するIssueがない場合は、`バグ` ラベルを付けて新しいIssueを作成する。
