## 実行した手順

### 1. CRANE-X7 パッケージの取得

```bash
cd ~/ros2_ws/src
git clone -b $ROS_DISTRO https://github.com/rt-net/crane_x7_ros.git
git clone -b $ROS_DISTRO https://github.com/rt-net/crane_x7_description.git
```

結果：成功。公開リポジトリなので GitHub のログインは不要。

### 2. sudo を使う手順

最初に次をまとめて貼り付けたところ、失敗した。

```bash
sudo rosdep init
rosdep update
sudo apt update
sudo apt install -y ros-jazzy-realsense2-camera
cd ~/ros2_ws && rosdep install -r -y -i --from-paths src
sudo usermod -aG dialout $USER
```

`sudo apt update` だけが実行され、ほかは実行されなかった（`/var/log/auth.log` で確認）。sudo がパスワードを聞いている間に、貼り付けた次の行がパスワードとして読み込まれたため。→ [troubleshooting](../troubleshooting.md) の「複数行を貼り付けると、sudo のあとの行が実行されない」

**1行ずつ** 実行し直して成功した。

```bash
sudo rosdep init
rosdep update
sudo apt install -y ros-jazzy-realsense2-camera
cd ~/ros2_ws && rosdep install -r -y -i --from-paths src
sudo usermod -aG dialout $USER
```

結果：

- `rosdep install` で 24 パッケージがインストールされた（MoveIt、ros2_control、Gazebo 連携、xacro、pcl_ros、rt_manipulators_cpp など）
- `rosdep check -r -i --from-paths src` → `All system dependencies have been satisfied`
- `getent group dialout` → `dialout:x:20:kaho`（ログインし直すと有効）

### 3. ビルド

```bash
cd ~/ros2_ws
colcon build --symlink-install
source ~/ros2_ws/install/setup.bash
```

結果：9 パッケージすべて成功（約 30 秒）。crane_x7_examples で PCL の CMake 警告（`Policy CMP0144 is not set`）が出るが、ライブラリ側の設定の話で動作には影響しない。

### 4. 動作確認（ロボットなしでできる範囲）

```bash
# パッケージが見えるか
ros2 pkg list | grep -E "^crane_x7|^realsense2|^tukamukai"

# launch ファイルが読み込めるか（引数の一覧が出れば OK）
ros2 launch crane_x7_examples demo.launch.py --show-args
ros2 launch crane_x7_gazebo crane_x7_with_table.launch.py --show-args
```

結果：crane_x7（7 個）、realsense2_camera（3 個）、tukamukai が表示され、launch ファイルも読み込めた。

## 追加：Gazebo シミュレーションの動作確認

```bash
# ターミナル1（普通のターミナルで。VSCode の中だと RViz が落ちる → troubleshooting）
ros2 launch crane_x7_gazebo crane_x7_with_table.launch.py

# ターミナル2（ターミナル1に "You can start planning now!" が出てから）
ros2 launch crane_x7_examples example.launch.py example:=pick_and_place use_sim_time:=true
```

結果：Gazebo と RViz が開き、pick & place のサンプルが約 13 秒で最後まで動いて正常終了した。途中で次の3つでつまずいた（[troubleshooting](../troubleshooting.md) の「シミュレーション」）。

- VSCode（snap 版）のターミナルから起動すると RViz が落ちる
- ウィンドウを閉じても move_group などが残る
- Gazebo が終了した状態でサンプルを動かすと `No state update received` で止まる
